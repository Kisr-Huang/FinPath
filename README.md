
# FinPath

FinPath 是一个使用 Python 开发的个人储蓄与复利规划工具，旨在帮助用户估算长期储蓄的增长情况，并比较不同投资期限下的预期结果。

## 当前功能

- 根据初始本金、每月追加金额、年收益率和投资年限估算期末资产。
- 计算累计投入金额与估算收益。
- 一次比较多个投资期限，例如 10 年和 20 年。
- 对非法输入进行基本校验。
- 使用 pytest 进行自动化测试。

## 环境要求

- Python 3.10 或更高版本
- pytest（运行自动化测试时需要）

## 运行程序

在项目目录下执行：

```bash
python main.py
```

程序会展示 10 年和 20 年的储蓄估算结果。

## 运行测试

安装 pytest：

```bash
python -m pip install pytest
```

运行全部测试：

```bash
python -m pytest -v
```

## 计算假设

- 年收益率以小数表示，例如 4% 对应 `0.04`。
- 月收益率按年收益率除以 12 计算。
- 每月追加资金按月末投入处理。
- 计算结果是基于固定收益率假设的数学估算，不代表实际投资回报。
